 ## Development Philosophy

 > **이해하고, 구현하고, 개선하는 개발을 지향합니다.**

 새로운 기술을 학습할 때 단순히 사용법을 익히는 것보다\
 그 기술이 어떤 문제를 해결하기 위해 만들어졌으며, 내부적으로 어떻게 동작하는지를 이해하려고 노력합니다.

 또한 학습한 내용을 직접 구현하고 다양한 문제에 적용해보면서\
 이론과 실제 개발 사이의 차이를 줄이는 것을 중요하게 생각합니다.
